# App fonts

FinApp uses TT Norms Pro through stable app-wide aliases:

- `Inter_400Regular` -> `TTNormsPro-Regular.otf`
- `Inter_500Medium` -> `TTNormsPro-Medium.otf`
- `Inter_600SemiBold` -> `TTNormsPro-DemiBold.otf`
- `Inter_700Bold` -> `TTNormsPro-Bold.otf`

The alias names are kept so existing screens do not need mass style rewrites.
